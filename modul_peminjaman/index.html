Wireframe UI — Modul Kegiatan Simpan Pinjam

Koperasi Serba Usaha Mitra Sejahtera · dokumen kerja untuk diskusi dengan programmer. Semua halaman statis (tanpa backend), memakai Bootstrap 5.3 lewat CDN tanpa CSS/JS kustom, dan diisi data dummy agar alurnya mudah dipahami.

Cara memakai: buka index.html ini di browser, lalu masuk ke dashboard tiap role melalui menu di atas (ada juga menu Pindah role pada navbar tiap halaman). Empat role: anggota, admin koperasi (bendahara), ketua, dan pengawas koperasi.

Catatan teknis untuk programmer

  • Semua halaman HTML statis: bootstrap@5.3.3 (CSS + bundle JS) dan bootstrap-icons dari CDN jsDelivr.
  • Tidak ada CSS kustom, tidak ada JavaScript tambahan — interaksi memakai komponen bawaan Bootstrap (modal, dropdown, tab, collapse) lewat atribut data-bs-*.
  • Tata letak memakai grid + utility class (row, col, d-flex, gap, table-responsive, ratio).
  • Angka angsuran dihitung nyata (metode flat, menurun, dan anuitas) sehingga konsisten antar halaman dan bisa dipakai programmer sebagai contoh keluaran yang diharapkan.
  • Form belum terhubung ke backend: nilai terisi statis, tombol hanya menggambarkan alur.

Perlu dikonfirmasi ke pengguna

  • Kriteria skor prioritas keperluan untuk ketua (urgensi, tenggat, kolektibilitas).
  • Rumus denda dan penalti pelunasan dipercepat per jenis pinjaman.
  • Kebijakan autodebet gagal: percobaan ulang, batas waktu denda, eskalasi.
  • Apakah pengawas cukup read-only atau perlu fitur catatan temuan yang tersimpan.
  • Format berkas XLSX dari bank (nama kolom & validasi NIK) untuk proses impor.
